# ADR-006: Embeddings — nomic-embed-text

**Статус:** Принято  
**Дата:** 11 мая 2026  
**Автор:** Алеся Мороз

---

## Scope

| Этап | Что реализовано | Статус |
|---|---|---|
| **MVP** | nomic-embed-text v1.5 через заменяемый embedding adapter, размерность 768; Ollama допустим как local-lite fallback | ✅ Текущее решение |
| **Scale** | Замена на bge-m3 или ruBERT-based модель при необходимости улучшения качества на русском; возможен переход на отдельный embedding server | 🔜 Вне скоупа MVP |

---

## Контекст

Synapse использует векторный поиск как один из двух компонентов гибридного GraphRAG. Качество эмбеддингов напрямую влияет на точность retrieval. Ключевые требования:

- Поддержка русского языка (основной язык корпуса)
- Self-hosted, без внешних API
- Self-hosted запуск через embedding adapter; Ollama допустим только как local-lite fallback
- Размерность вектора совместима с Qdrant коллекцией (768 или 1024)
- Приемлемое качество на коротких корпоративных текстах (регламенты, инструкции)

---

## Решение

**nomic-embed-text v1.5** — запуск через embedding adapter, размерность 768, дистанция COSINE в Qdrant. В local-lite режиме допускается backend через Ollama (`ollama pull nomic-embed-text`); в GPU Dev adapter может быть реализован отдельным Python/HTTP-сервисом.

```python
embeddings = EmbeddingAdapter(model="nomic-embed-text")
vector = embeddings.embed_query("Как получить доступ к GitLab?")
# → список из 768 float значений
```

## Альтернативы рассмотрены

| Вариант | Плюсы | Минусы | Решение |
|---|---|---|---|
| **bge-m3 (BAAI)** | Лучшее качество на русском по MTEB, поддержка dense + sparse + colbert | Размер модели ~570MB, требует отдельного сервиса (не через Ollama напрямую), сложнее интеграция | **Отклонён для MVP**, приоритет для Scale |
| **multilingual-e5-large (Microsoft)** | Хорошее качество на многих языках включая русский, размерность 1024 | Требует отдельного сервиса HuggingFace, не интегрирован в Ollama | **Отклонён** |
| **ruBERT / sbert-ru (DeepPavlov)** | Специализирован под русский язык | Устаревшая архитектура (BERT 2019), уступает современным моделям по качеству | **Отклонён** |
| **text-embedding-ada-002 (OpenAI)** | Эталонное качество, простая интеграция | Данные покидают периметр, нарушает ФЗ-152 | **Отклонён** (блокер по безопасности) |
| **all-MiniLM-L6-v2 (sentence-transformers)** | Лёгкая модель, быстрая, хорошо на английском | Слабое качество на русском языке | **Отклонён** |

## Trade-offs

**Плюсы nomic-embed-text:**
- Может запускаться через простой adapter; Ollama остаётся fallback для local-lite
- Поддержка русского языка подтверждена бенчмарками MTEB (Multilingual)
- Размерность 768 — оптимальный баланс качества и скорости поиска в Qdrant
- Матрёшка-эмбеддинги: поддержка усечения размерности без переиндексации
- Лицензия Apache 2.0

**Минусы nomic-embed-text:**
- Уступает bge-m3 на специализированных русскоязычных бенчмарках (~3-5% по NDCG@10)
- Качество на узкоспециализированной корпоративной терминологии не тестировалось на production объёмах
- При переходе с Ollama fallback на отдельный embedding service нужно сохранить контракт adapter и переиспользовать размерность 768

---

## Последствия

- Коллекция Qdrant создаётся с `size=768, distance=Distance.COSINE`
- Все документы индексируются через `nomic-embed-text` — смена модели требует полной переиндексации
- При Scale-переходе на bge-m3 (размерность 1024) — пересоздание коллекции Qdrant и переиндексация корпуса
- Качество retrieval оценивается на тестовом наборе из 20 вопросов (PoC гипотеза: точность >80%)

---

## Compliance & Ethics

**Регуляторное соответствие:**
- nomic-embed-text запускается полностью локально через embedding adapter или Ollama fallback — данные не покидают периметр, требования **ФЗ-152** соблюдены
- Лицензия **Apache 2.0** — коммерческое использование допустимо без ограничений

**Этические риски и меры снижения:**
- Риск низкого качества retrieval на русскоязычных текстах → галлюцинации LLM из-за нерелевантного контекста. Мера: оценка качества retrieval на golden dataset из 20 вопросов до сдачи MVP; при Context Recall < 0.8 — замена на bge-m3
- Риск семантического смещения: модель может не различать близкие корпоративные термины («деплой» vs «выкатка»). Мера: Domain Ontology (FR-39) нормализует термины до индексации, снижая зависимость от качества эмбеддингов
