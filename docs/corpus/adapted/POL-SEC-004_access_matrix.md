## 1. Назначение

Настоящий документ является исчерпывающей матрицей доступов ко всем информационным системам Synapse Corp. Матрица служит операционным справочником для IT-отдела при предоставлении, изменении и отзыве доступов. Политика управления доступами описана в `POL-SEC-001`.

---

## 2. Условные обозначения

| Обозначение | Значение |
|---|---|
| ✓ | Полный доступ |
| R | Только чтение |
| — | Доступ отсутствует |
| * | Временный / по заявке |

## 4. Сервисные аккаунты

Сервисные аккаунты (используемые приложениями, CI/CD пайплайнами) управляются отдельно:

| Аккаунт | Назначение | Владелец |
|---|---|---|
| `ci-deploy` | Деплой через GitLab CI | DevOps |
| `qdrant-service` | Доступ к Qdrant из backend | DevOps |
| `neo4j-service` | Доступ к Neo4j из backend | DevOps |
| `langfuse-service` | Запись трейсов | DevOps |

- Сервисные аккаунты не используются людьми для интерактивной работы
- Ротация ключей сервисных аккаунтов — ежеквартально
- Управление сервисными аккаунтами — исключительно Admin (уровень 5)

---

## 5. Исключения

Исключения из матрицы (временный доступ выше уровня роли) оформляются через `POL-SEC-001` раздел 3.2. Все исключения логируются и проверяются в рамках квартального аудита.
